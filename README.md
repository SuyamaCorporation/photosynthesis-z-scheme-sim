# Photosynthesis Z-Scheme Electron Flow Sim

## 概要
光合成の明反応（Zスキーム）での電子伝達・光化学系I/IIの励起と酸化還元ポテンシャル変化をエネルギーダイアグラムでアニメーション表示するインタラクティブシミュレーター。

## 機能
- 縦軸を酸化還元電位（−1.2V〜+0.82V）としたZスキームエネルギーダイアグラム
- PSII (P680)・フェオフィチン・PQ・Cyt b6f・PC・PSI (P700)・Fd・FNRの全コンポーネント表示
- Startボタンで8段階の電子流アニメーション（各ステップの経路ハイライト）
- 水分解によるO₂生成・FNRによるNADPH産生を視覚化
- 各コンポーネントをクリックすると詳細情報（酸化還元電位・機能説明）を表示
- 色分け: 励起状態（黄）・酸化型（赤）・還元型（青）
- 進捗バー・ステップリストでアニメーション進行を追跡
- Autoモードで繰り返し再生

## 使い方
1. `▶ Start` ボタンでアニメーション開始
2. 各コンポーネント（P680, PQ, Cyt b6f等）をクリックして詳細確認
3. `⏸ Pause` / `▶ Continue` で一時停止・再開
4. `↺ Reset` でリセット
5. `Auto` ボタンで自動ループ再生
